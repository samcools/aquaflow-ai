# Risk and Lifecycle Colour Semantics

AquaFlow uses consistent visual status colours across cards, table chips, risk registers, projects, incidents, work orders and approvals.

- **Critical / escalated / failed / rejected / blocked:** red.
- **High / at-risk / delayed / overdue / attention:** orange.
- **Medium / watch / pending / review:** amber.
- **Low / on-track / healthy / approved / completed / closed / verified:** green.
- **Open / active / in-progress / dispatched / assigned:** blue.
- **Mitigating / repair-in-progress / verifying:** cyan/teal.
- **Accepted / planned / proposed:** purple.
- **Cancelled / archived / inactive:** neutral grey.

Colour is always accompanied by visible status text; it is never the only status signal.
