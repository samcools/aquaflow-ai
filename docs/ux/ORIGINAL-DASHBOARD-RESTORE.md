# Original Dashboard Restoration Target

The AquaFlow application must preserve the original Project Guardian-style visual system shown in the approved reference screenshot while retaining AquaFlow functionality underneath.

Required visual characteristics:
- deep navy/royal-blue horizontal application header;
- Pyrneo and AquaFlow branding integrated without oversized hero treatment;
- compact navigation tabs across the top;
- thin demo/workspace banner directly below the header;
- five compact KPI cards in the first row;
- left-side AI assistant card with the single global Ayanda identity;
- large central graphical operational/status panel;
- right-side assurance/compliance/controls panel;
- lower-row operational cards such as allocation, recent activity, milestones, risks and recovery;
- white cards with fine light-blue borders, restrained shadows and compact information density;
- no oversized whitespace, no full-height left sidebar, no excessive gradients, and no oversized floating decorative UI;
- responsive collapse for tablet/mobile while maintaining the same design language.

Functional modules, APIs, security controls and data models must not be removed by the visual restoration.
