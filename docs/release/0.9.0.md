# AquaFlow AI 0.9.0

This release focuses on demo polish, voice quality and secure OpenAI configurability.

- Uses the first AquaFlow AI visual design rather than the Project Guardian shell.
- Displays one visible brand logo: the transparent Pyrneo wordmark. AquaFlow AI remains the product name in text; the separate AquaFlow icon is hidden.
- Compacts the Recovery Pulse card so it sizes to its content and no longer wastes vertical space.
- Adds distinct colours for critical, high, medium, low and lifecycle risk/status states.
- Adds OpenAI neural text-to-speech for Ayanda, configured as a warm professional South African female persona.
- Adds user-selectable OpenAI voices with Coral as the default and browser speech as fallback only when neural speech is not configured.
- Adds in-product OpenAI API-key configuration. In-app keys are ephemeral, session-scoped and never echoed or persisted to GitHub/browser storage/demo records.
- Routes grounded questions through OpenAI when configured while retaining deterministic fallback.
- Keeps commands and record mutations behind existing RBAC, tenant validation and audit controls.
- Retains multilingual voice recognition, Hey Ayanda activation and one global chatbot/voice pipeline.
