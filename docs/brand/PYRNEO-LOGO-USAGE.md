# Pyrneo logo usage

AquaFlow must use the user-supplied Pyrneo wordmark as the primary visible logo. The source raster is `frontend/pyrneo-logo.webp`, derived from the supplied wordmark. The UI removes the source black background at runtime so the displayed mark is transparent while preserving the supplied artwork. Do not redraw, replace, recolour or substitute the Pyrneo wordmark.

Placement rules:
- Login: maximum width 300px, responsive.
- Sidebar: approximately 172px desktop, 150px mobile.
- Background remains transparent.
- Clicking the logo returns to the AquaFlow Command Centre/home view.
